# 安装、诊断与恢复

## 我只想直接用桑多涅主题

下载 Windows-x64 完整版，完整解压，先双击“检查安装.cmd”，再双击“安装快捷方式.cmd”。手动完全退出已有 Codex 后，从桌面“桑多涅 Codex（分享版）”启动。

普通用户不需要 Git、Node 安装器、Python、npm 或编译工具；程序包已带必要运行时。仍需自己安装官方 Windows Codex、登录自己的账号。Lite 只有原创几何占位图，不能期待它显示桑多涅立绘和视频。

## 提示找不到官方客户端

本包不会替你安装 Codex。先安装官方 Windows 版，正常打开一次，然后重新运行“检查安装.cmd”。不要把别人的 machine.json 复制过来。

## 提示文件校验失败

重新下载完整 ZIP、对照 SHA256SUMS.txt，解压到新的本机可写目录。不要跳过校验。开发者修改代码或素材后需要重新运行“从源码构建.cmd”生成清单。

## 主题启动不出来

确认原来的 Codex 已从托盘完全退出。不要不断重复双击；查看官方窗口是否正在等待手动登录。端口冲突、进程身份不符或文件损坏时启动器会拒绝接入。不要开放防火墙或让调试端口监听局域网。

## 恢复官方界面

保存工作后运行“一键恢复官方原版.cmd”；恢复可能正常退出本项目主题窗口。最直接的应急方式是手动从托盘退出主题版，再打开原来的官方入口。官方安装文件一直没有修改。不要删除整个 .codex 或其他账号目录。

## 换文件夹与卸载

移动未运行的解压目录后重新安装快捷方式。运行“移除快捷方式.cmd”只处理指向当前目录的分享版入口。退出主题版后可自行删除目录；其中 profile/ 是你自己的主题版登录数据，保留或删除由你决定，不要再分享。

记录官方 Codex 版本、Windows 版本、主题发行版、原生外观和最短复现步骤。截图先隐藏私人内容。不要上传 profile/、state/、machine.json、.codex/ 或使用过的整个程序目录；公开源码已有隐私忽略规则。
