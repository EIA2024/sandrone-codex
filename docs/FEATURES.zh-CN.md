# 已实现的功能与细节

以下角色美术效果指 Windows 完整版；本仓库已包含实际桑多涅素材，代码与美术分别注明许可。

## 开屏

- 与官方 Codex 同一窗口，描边、显色、淡出后进入原生工作界面。
- 人物暖橙色矢量轮廓，脸部、头饰、卷发与服装主体保留辨识度。
- 原视频的大齿轮与后续水纹单独预渲染为冰蓝描边，与彩色视频同步。
- 显色不 seek、不重新从第零帧播放，保留齿轮转动与水波的连续性。
- 水中另一套服装的倒影来自原片；不密集描摹水下人物，没有额外开头同心圆。
- 1080p 静音循环视频；离开开屏后停止并释放媒体，不把聊天背景变成常驻视频。
- 根据用户手写参考重描的 Sandrone 矢量签名，约一秒逐笔写出。
- FATUI / NO. 007、MARIONETTE、小头像、三枚纹章、漂浮光点、扫光与金色角饰。
- 加粗 CodeX；解算开始。→填入变量。→进程良好。→析构万理！啊哈哈哈...（文字，无语音）。
- 双击、连续两次空格/Enter 或 Esc 跳过；重播不重启、不重新发送任务。
- 结合真实就绪状态与最短演出时间淡出，超时退让，视频失败有静态兜底。
- 支持系统减少动态效果偏好。

## 工作界面

- 右侧保留桑多涅立绘，聊天区和右侧工具栏透明，阅读卡片使用深色底。
- 黑金侧栏、象牙白文字、深蓝输入框与金色细边。
- 首页文案：机巧镀形，万理澄清。
- 按钮悬停、按下、金色键盘焦点；保留实心/禁用/危险操作/勾选状态。
- ChatGPT 正文、代码、新建项目、菜单、Tooltip、设置和活动状态使用匹配的深色配色。
- 打开模态弹窗或图片查看器时重播按钮自动隐藏，为原生关闭键让位。
- 窗口最小化/最大化/关闭仍为系统原生按钮，配色衬底随只读原生主题信号更新。

## 运行与恢复

- 使用官方客户端，无自制 AI 后端；独立 profile，不复制制作者或用户已有凭据。
- 解压位置可变；自动发现本机官方安装，不要求 D 盘。
- 固定本机回环调试接口；验证进程、启动时间、监听归属与 browser ID。
- 就绪窗口复用，监视器事件唤醒；同版本 CSS 修改也会正确更新。
- 文件 SHA256 清单、Node 签名检查、独立桌面入口和一键恢复。
- 不包含官方程序、账号、模型额度、聊天记录或 MCP 配置。

待各使用者验证：自己的客户端版本、真实冷启动、聊天发送、MCP/模型和审批交互。主题依赖官方界面结构，更新可能需要适配。
